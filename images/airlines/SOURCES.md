Retrieved 21 October 2026. Aircraft images come from the airlines' fleet pages; logos are airline PNG assets served by the Aviasales image CDN. Source URLs are listed above. The JavaScript download utility has been removed along with the scripts directory.

Flight schedules, package rules, taxes and prices are illustrative, authored directly in `search-flight.html`. All totals are prewritten HTML; the page does not load JavaScript, fetch inventory, or calculate fares. Three independent cards demonstrate one-way, round-trip and multi-city journeys; the multi-city example includes Doha and Karachi. Native radios and CSS select static fare packages and quotes. The top trip selector changes only the search form, not these examples. The range controls are visual form inputs in this static preview.
